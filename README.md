# SQL & PL/SQL Data Processing Project

## Project Overview

This project demonstrates a sample data processing workflow using SQL and PL/SQL concepts. It includes table creation, data validation checks, transformation logic, and reporting queries commonly used in ETL and data warehousing environments.

## Skills Demonstrated

- SQL table design
- Data validation
- Data quality checks
- Joins and aggregation
- Reporting queries
- ETL-style data processing logic
- Data warehousing fundamentals
